## Открытые вопросы

- Дозапись демо при живом хабе: перед `make record-demo` убрать из `app/demo_data/llm/parse.json` и `evaluate.json` поправленные вручную записи — запись переиспользует записанное.
- «Разобрать описание» выполняется синхронно в асинхронном обработчике и на 10–30 с блокирует сервер для всех вкладок — вынести в фоновую задачу.
- «Удалить ключ» стирает ключ только в «Настройках»; из `.env` он берётся по-прежнему.
- В записанных «Кратко» остались формулировки и цитаты, которых нет в тексте резюме, — у них стоит «проверьте».
