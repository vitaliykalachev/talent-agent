# Отчёт по этапу 4 — ночь, порядок, поставка

Ветка `stage-4-night`, последний рабочий коммит `e805db0`, свежий `main` (этапы 2–3) влит в `19196ef` без конфликтов. `make test` — 257 тестов за 37 с, `make lint` чистый. `make demo` без `LLM_API_KEY` собирает базу за 15–20 с; экраны «Главная», «Утро», «Вакансии», «Результат по вакансии», «Похоже на дубль», «Настройки», «Загрузка базы», «Кандидаты» отвечают 200; на «Утре» — «Начальник литейного производства: 3 подходят, 15 можно рассмотреть».

## Сделано

1. Решения по этапу 3: «Можно рассмотреть» только при половине обязательных «есть» или «частично», иначе «Скорее не подходят» (тест: 1 обязательное из 5 при балле выше 55); остальное оставлено.
2. Расписание `app/schedule.py`: APScheduler, `coalesce=True`, запас 6 часов, cron из `night_time` и `night_days`. Задача `night` (`app/night.py`): помечает устаревшие, ищет возможные дубли, считает отпечатки, оценивает только новых по вакансиям с «Оценивать каждую ночь»; итог в `night_runs` (миграция `0004`); опоздание — `summary.late`, пропуск дольше запаса — `missed`, сбой — `failed`; кнопка «Запустить сейчас»; у вакансии галочка «Оценивать каждую ночь».
3. «Утро» (`app/morning.py`): четыре раздела со ссылками; сорванный прогон — первой строкой причина и «Запустить сейчас»; пустое утро — свой текст; на «Главной» — «Этой ночью в 02:00: …».
4. Письмо (`app/mail.py`): SMTP из «Настроек», «Отправить пробное письмо», сторож — в письме нет ФИО, телефонов и почты; без SMTP письмо не уходит, «Утро» работает.
5. Дубли: возможные — по ФИО плюс год рождения или общий работодатель; экран пары — две карточки, совпавшие поля жёлтым, причина словами, «Объединить» (с выбором поля), «Нет, это разные люди», «Отложить»; любое слияние обратимо — снимок основной записи в `duplicates.snapshot`.
6. «Настройки»: блоки «Ночной прогон», «Почта для отчёта», «Что уходит модели», «Агент запомнил» с «Удалить» и «Забыть все исправления».
7. `make record-demo` записывает ответы в `app/demo_data/llm/`: 303 разбора, разбор вакансии, 47 оценок; повторный запуск платит только за недостающее.
8. Загрузки подписаны «Загрузка 26 сен, 14:05 · crm_export.xlsx»; фильтр «Из загрузки…» на «Кандидатах»; «История загрузок» в «Загрузке базы».
9. `README.md` для пользователя, `docs/DEV.md` для разработчика, четыре скриншота в `docs/screenshots/`.
10. `compose.yaml` с томом `data/` и `127.0.0.1:8000`; сборка не проверена — Docker на машине нет.
11. Тесты: `tests/test_night.py`, `tests/test_merge.py`, `tests/test_web_stage4.py`, `make demo` без ключа в `tests/test_demo.py`.

## Правки по ревью этапа 3 (все 12, с тестами)

Первые две — коммит `22b845c`, остальные — `fc444c5`: предложения описания про возраст, пол и семью не уходят в модель (сторож по `mock.calls`); транзитивная склейка через «Иванов Иван» убрана, пара уходит в `open`; строка из меток и подписей контактов не опора; оценка сохраняется по каждому кандидату (после сбоя повторно уходит один); `inf`/`1e999`/`nan` в условиях → 400; `start()` видит паузу; таблица «Вакансии» — `stack`; `back` только вида `/путь`; регулярка ловит «25–35 лет», «девушка», «парень», «молодой», «холост» и не ловит «3–5 лет в литье»; сырой ответ в `matches.raw_checks`, счётчики `eval/` по нему; телефон с переносом строки и «Мне 45 лет» маскируются; нечисловой `candidate_id` → 400, несуществующий id в оценке пропускается с пометкой, оценка без требований → «Не удалось оценить»; набор проверки — 5 вакансий вместо 20.

## Запись демо

300 разборов (claude-haiku-4.5), разбор вакансии и 47 оценок (claude-sonnet-5) — около 206 ₽ по тарифам из «Настроек» (первая запись ≈ 97 ₽ упала после 118 разборов на ответе не по форме, вторая ≈ 109 ₽, третья сорвалась на недоступном хабе). Не записаны разборы трёх записей «Похоже на дубль» — хаб перестал отвечать около 04:20; повторный `make record-demo` оплатит только их.

## Отклонения

- В демо 303 записи: три возможных дубля дописаны в конец выгрузки, чтобы очередь «Похоже на дубль» не была пустой; разметка `eval/` прежняя, критерий по Recall@40 проходит.
- Записанные оценки перенесены на новый порядок записей по ID из CRM, текст сверен кодом.
- Дата демо зафиксирована днём записи (27.09.2026).
- Ночью резюме не разбираются, только считаются отпечатки.
- Слово `smtp` добавлено в запрещённые на экранах.
